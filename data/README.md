# Public data

Problem records in this directory are English-only JSON files validated by
`data/schema/problem.schema.json`. The public release contains problem
statements, cited public progress, and complete formalizations of three scoped
principal theorems. Other internal solutions and uncleared Lean sources are
intentionally absent.

Anonymous or unpublished internal progress is intentionally omitted from
public records. Timeline entries identify a source statement or a public
literature/verification event.

`data/manifest.json` lists the release version, record count, and the source
families intentionally excluded from the public index.

Records are added only after source, status, citation, artifact scope, and
license review. See [`DESIGN.md`](../DESIGN.md) for the corpus audit and
publication policy.
